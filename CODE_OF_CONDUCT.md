# Code de conduite — Contributor Covenant 2.1

## Notre engagement

Nous, membres, contributeurs et responsables de ce projet, nous engageons à faire
de la participation une expérience sans harcèlement pour tout le monde, quels que
soient l'âge, la taille, le handicap visible ou invisible, l'origine, le sexe,
l'identité de genre, le niveau d'expérience, la formation, le statut socio-économique,
la nationalité, l'apparence, la couleur de peau, la religion ou l'orientation sexuelle.

## Nos standards

Exemples de comportement qui contribuent à créer un environnement positif :
- faire preuve d'empathie et de bienveillance envers les autres ;
- respecter les opinions, points de vue et expériences différents ;
- donner et accepter gracieusement les critiques constructives ;
- assumer ses erreurs et s'excuser auprès des personnes affectées ;
- se concentrer sur ce qui est meilleur pour la communauté.

Exemples de comportements inacceptables :
- langage ou imagerie sexualisés, avances ou attouchements non sollicités ;
- trolling, commentaires insultants ou désobligeants, attaques personnelles ou politiques ;
- harcèlement public ou privé ;
- publication d'informations privées d'autrui sans autorisation explicite ;
- toute conduite qui serait raisonnablement considérée comme inappropriée dans un cadre professionnel.

## Application

Les responsables du projet clarifient et appliquent ces standards. Ils peuvent
supprimer, modifier ou rejeter commentaires, commits, code, issues et PR qui
violent ce code de conduite.

## Signalement

Tout comportement abusif peut être signalé en privé aux responsables du projet via
[GitHub — signaler un abus](https://github.com/mjcc30/auris/issues/new?template=code_of_conduct.md)
ou par [security advisory privé](SECURITY.md). Tous les signalements sont traités
de façon confidentielle.
