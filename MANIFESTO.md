# Manifeste Auris

Auris est un lecteur de musique pour les gens qui écoutent vraiment.

## Nos principes

1. **L'audio d'abord, bit-perfect.** Aucun ré-échantillonnage, aucun traitement
   caché. PCM jusqu'à 32 bit / 768 kHz, DSD jusqu'au DSD256, délivré tel quel au DAC.
   Le volume logiciel est optionnel et contournable (bit-perfect).

2. **Un seul binaire, clé en main.** Pas de runtime à installer, pas de dépendance
   exotique. Sur un Raspberry Pi, une commande installe, une commande lance.
   Le binaire embarque même son interface web.

3. **Vos données restent chez vous.** Zéro télémétrie, zéro compte, zéro cloud
   obligatoire. Auris parle à votre NAS sur votre réseau local, point.

4. **Copyleft : AGPL v3.** Le code est libre et le reste. Toute version modifiée
   et distribuée remet son code source à disposition — c'est ce qui protège le
   projet d'une capture commerciale.

5. **La communauté branche des extensions.** Comme les plugins Volumio, mais ouverts :
   n'importe quel langage, un manifeste déclaratif, un protocole simple.
   Voir [docs/PLUGIN_SYSTEM.md](docs/PLUGIN_SYSTEM.md).

6. **Pensé pour durer.** Matériel réparable, logiciel maintenable, formats ouverts,
   pas de DRM. Un lecteur acheté en 2026 doit tourner en 2036.

7. **Accessibilité et sobriété.** Interface lisible (WCAG 2.1 AA), consommation
   mémoire < 150 Mo, utilisable au clavier, traduite (fr/en à terme).

8. **Pas de dark patterns.** Pas de bouton "accepter tout", pas d'upsell, pas de
   compte obligatoire. La musique, c'est tout.

*« L'oreille avant tout. »*
